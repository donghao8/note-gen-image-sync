# Agentic Context Engineering: Evolving Contexts for Self-Improving Language Models

**摘要**：大型语言模型（LLM）应用（如智能体和特定领域推理） 严重依赖上下文适应——通过指令、策略或证据修改输入，而非权重更新。先前的方法虽然提升了可用性，但往往存在简洁性偏差（为追求简明摘要而丢失领域洞察）以及上下文坍塌问题（迭代重写随时间推移侵蚀细节）。

基于 Dynamic Cheatsheet（动态备忘录） 提出的自适应记忆机制，我们提出了 ACE（Agentic Context Engineering），该框架将上下文视为不断演化的“剧本（playbook）” ，通过生成、反思和整理的模块化流程来积累、优化和组织策略。ACE 采用结构化、渐进式更新，保留详细知识，并与长上下文模型协同扩展，从而防止上下文坍塌。

在智能体和特定领域基准测试中，ACE 能够对离线上下文（例如系统提示）和在线上下文（例如智能体记忆）进行优化，持续优于强基线：在智能体任务上提升 $+10.6\%$，在金融领域提升 $+8.6\%$，同时显著降低适应延迟和推理成本。值得注意的是，ACE 无需标注监督，而是利用自然执行反馈实现有效适应。在 AppWorld 排行榜上，ACE 使用更小的开源模型，整体平均表现匹敌排名最高的生产级智能体，并在更具挑战性的测试集上超越其表现。

这些结果表明，全面且持续演化的上下文能够实现可扩展、高效、自我改进且开销低的 LLM 系统。

# 1、Introduction

基于大语言模型（LLMs）的现代人工智能应用，例如LLM智能体[49, 52]和复合AI系统[55]，越来越依赖*上下文适应（Context Adaptation）*。与修改模型权重不同，上下文适应通过在模型输入中直接引入明确的指令、结构化推理步骤或特定领域的输入格式，可在模型训练后提升性能。上下文支撑着许多AI系统组件，包括指导下游任务的系统提示[4, 36]、存储过去事实和经验的记忆[41, 48]，以及减少幻觉并补充知识的事实证据[6]。

通过上下文而非权重进行适应具有多个关键优势。上下文对用户和开发者而言是可解释且可理解的 [45, 47]，能够在运行时快速集成新知识 [7, 27]，并且可以在复合系统中的不同模型或模块之间共享 [23]。同时，长上下文大语言模型的发展 [39] 以及上下文高效的推理技术（如 KV 缓存复用 [17, 51]）正使得基于上下文的方法在部署中日益实用。因此，上下文适应正逐渐成为构建能力强、可扩展且能自我改进的人工智能系统的核心范式。
